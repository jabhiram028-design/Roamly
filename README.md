# Roamly — Explore. Experience. Belong.

A modern, luxury travel & tourism web application built with React 19, TypeScript, Vite, and Tailwind CSS v4.

## 🌟 Features

- **Hero & Search**: Santorini visual hero with real-time destination auto-suggestions.
- **Popular Destinations**: Curated interactive destination cards with hover zoom and wishlist toggles.
- **Travel Your Way**: 8 distinct travel style filters (Adventure, Solo Travel, Sustainable, Honeymoon, etc.).
- **Featured Trips**: Multi-day itinerary packages with duration tags and booking modal triggers.
- **Day-by-Day Itineraries**: Detailed trip itineraries with collapsible schedules and inclusions/exclusions checklists.
- **Travel Guides Journal**: Magazine-style editorial articles with interactive modal reader.
- **Interactive Modals**: Multi-step booking request with price calculations, search modal, and sign-in/sign-up.
- **Wishlist Storage**: Persistent saved collection using `localStorage`.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Google Fonts (Playfair Display & Plus Jakarta Sans)
- **Icons**: Lucide React
- **State Management**: React Context API

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
